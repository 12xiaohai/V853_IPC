# 阶段9.1：NPU环境与单帧推理技术说明

## 1. 阶段目标

本阶段先把NPU推理从摄像头、显示、编码、RTSP和录像链路中隔离出来，验证：

1. 板端模型文件可以读取；
2. AWNN能够解析模型信息；
3. NPU运行内存能够初始化；
4. 网络可以创建并接收NV21输入；
5. 单帧推理和人形后处理能够完成；
6. 退出时网络、NPU内存和测试缓冲均正常释放。

独立验证通过后，阶段9.2再创建专用低分辨率VI通路并接入实时视频帧。这样出现
问题时可以明确区分“模型或NPU问题”和“实时视频输入问题”。

## 2. 与原项目的对应关系

原项目的`ipcamera.conf`配置为：

```text
nn_enable = 1
nn_type = 0
```

`nn_type=0`使用全志人形检测模型：

```text
/lib/1.1.0_Beta.nb
```

原项目同时包含`yolov8n.nb`和一套YOLOv8通用目标后处理代码，但当前配置并
没有启用它，而是使用`AWNN_DET_POST_HUMANOID_1`做人形检测。因此复刻阶段先
恢复原项目实际启用的人形链路；YOLOv8通用模型可以在基础链路稳定后作为模型
切换和对比项接入。

原项目的人形处理顺序为：

```text
awnn_get_info
    -> awnn_init
    -> awnn_create
    -> awnn_set_input_buffers
    -> awnn_run
    -> awnn_det_post
    -> awnn_destroy
    -> awnn_uninit
```

阶段9.1保留了这一顺序，但只运行一帧，不创建实时检测线程。

## 3. 输入图像格式

模型信息决定可见宽高，当前人形模型预期为`320x180`。V853的输入缓冲高度按
32像素对齐，因此内存布局为：

```text
Y平面：  320 x 192
VU平面： 320 x 96
总大小： 320 x 192 x 3 / 2 = 92160字节
```

自检程序支持两种文件：

- 紧凑`320x180` NV21：86400字节；
- 已对齐`320x192` NV21：92160字节。

读取紧凑文件时不能直接整体复制。程序先把180行Y写入对齐Y平面，再把VU写到
第192行之后的色度平面位置；补齐区域使用NV21黑色值`Y=16、VU=128`。

没有传入图像时，程序使用全黑NV21帧。全黑帧通常检测不到人，但只要推理完成
就能证明模型加载和NPU运行链路正常。检测正确性需要再使用含人的真实测试帧。

## 4. 独立运行方式

### 4.1 检查模型

```sh
ls -lh /lib/1.1.0_Beta.nb
```

若模型不存在，可从原SDK的以下位置复制到开发板：

```text
aw_pack_src/other/models/viplite-driver/1.1.0_Beta.nb
```

### 4.2 黑帧基础自检

```sh
./sample_strip --npu-self-test
```

该模式不会启动MPP摄像头、LCD、编码、RTSP、音频或录像服务。

### 4.3 使用真实NV21图片

```sh
./sample_strip --npu-self-test \
    /lib/1.1.0_Beta.nb \
    /mnt/UDISK/npu_test_320x180.nv21
```

可以在电脑上把之前保存的1920x1080 NV21帧缩放为模型输入：

```sh
ffmpeg -f rawvideo -pixel_format nv21 -video_size 1920x1080 \
    -i preview_frame_1920x1080.nv21 \
    -vf scale=320:180 -frames:v 1 -pix_fmt nv21 -f rawvideo \
    npu_test_320x180.nv21
```

将生成的文件复制到开发板`/mnt/UDISK`后再运行自检。

## 5. 预期日志

模型信息：

```text
[NPU] Model: name=..., md5=..., input=320x180, aligned=320x192,
      memory=..., recommended_threshold=...
```

黑帧自检：

```text
[NPU] No input file supplied; using a black NV21 frame
[NPU] Single-frame inference succeeded: cost=... us, objects=0, threshold=0.250
```

含人的真实帧可能输出：

```text
[NPU] Result[0]: label=0, score=..., box=(xmin,ymin)-(xmax,ymax)
```

`objects=0`不等于NPU失败，它只表示当前输入没有超过阈值的目标。是否成功应以
`Single-frame inference succeeded`和程序退出码为准。

## 6. 安全设计

- 模型宽高必须为正数、偶数且不超过4096；
- 模型内存需求不能为0；
- 输入文件大小必须严格匹配紧凑或对齐NV21大小；
- 使用`CLOCK_MONOTONIC`测量耗时，避免NTP校时造成负耗时；
- 任一阶段失败都进入统一清理路径；
- 只有`awnn_init()`执行后才调用`awnn_uninit()`；
- 只有网络创建成功后才调用`awnn_destroy()`。
